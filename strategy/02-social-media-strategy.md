# 社交媒體策略

## 平台選擇及定位

### 平台優先級

| 平台 | 優先級 | 目標用戶 | 內容類型 | 發文頻率 |
|------|--------|----------|----------|----------|
| **Facebook** | 主力 | 公屋區街坊、40-70歲長者、家庭主婦 | 圖文 + 短片 | 每週3篇 |
| **Instagram** | 次要 | 25-45歲上班族、年輕家庭 | Reels短片 + 圖片 | 每週2篇 |
| **小紅書** | 補充 | 注重養生嘅用戶、年輕女性 | 圖文筆記 | 每週1-2篇 |

### 點解揀呢三個平台？

- **Facebook**：公屋區街坊最常用，有大量屋邨社區群組；長者使用率高
- **Instagram**：Reels短片觸及率極高，可以免費觸達大量新用戶
- **小紅書**：健康養生類內容流量大，搜索導向（用戶主動搵健康資訊）

## Facebook 策略（主力平台）

### 專頁設定清單

- [ ] 建立Facebook專頁（選擇「醫療與健康」類別）
- [ ] 上載專頁頭像（診所logo或醫生專業照）

### Facebook群組策略（重要！）

呢個係零預算最有效嘅方法之一：

1. **搵出你嘅社區群組**：
   - 搜索「[屋邨名稱]」、「[區名] 街坊」、「[區名] 資訊」
   - 常見群組名：「XXX邨互助群」、「XXX區街坊會」
   - 搵到後申請加入

2. **群組發文策略**：
   - **唔好直接賣廣告**（會被ban）
   - 以「街坊分享」嘅身份分享健康知識
   - 範例：「最近天氣轉涼，好多人都話膝頭痛，分享幾個簡單穴位按壓方法...」
   - 有人問健康問題時主動回覆（展示專業）
   - 每週在群組分享1-2次（唔好太頻密）

3. **群組發文範例**：
```
各位街坊早晨！🌅

最近天氣反覆，好多人都覺得成身骨痛，尤其係膝頭同腰。
呢個係因為濕氣重，影響咗經絡運行。

分享2個簡單方法幫你紓緩：
1. 每日用薑水浸腳15分鐘
2. 按壓足三里穴（膝蓋下方四指位置）每邊30秒

如果痛症持續超過一星期，建議搵中醫睇下，及早處理效果更好。

祝各位身體健康！💪
```

## Instagram 策略

### 帳號設定

- [ ] 建立Instagram Business帳號（與Facebook專頁連結）
- [ ] 頭像：同Facebook一致
- [ ] Bio撰寫（150字以內）：

```
📍 [區名] 社區中醫診所
💪 專治痛症 | 針灸推拿 | 中藥處方
👨‍⚕️ 註冊中醫師 [醫生姓名]
📱 WhatsApp預約👇
```

- [ ] Bio連結設定WhatsApp預約連結
- [ ] 開啟Instagram Shopping（展示服務）

### IG內容策略

| 內容類型 | 格式 | 頻率 |
|----------|------|------|
| Reels短片 | 30-60秒直式影片 | 每週1-2條 |
| 圖片帖文 | Canva設計單圖/多圖 | 每週1篇 |
| Story | 日常分享、投票互動 | 每日1-2個 |

### Reels內容主題

1. **「一分鐘學穴位」系列** — 醫生示範穴位按壓
2. **「痛症知多啲」系列** — 簡單解釋常見痛症
3. **治療過程花絮** — 拔罐、針灸過程（已獲同意）
4. **「中醫冷知識」** — 有趣嘅中醫知識
5. **養生湯水** — 季節性湯水推介

### Reels拍攝Tips

- 直式拍攝（9:16）
- 前3秒要吸引注意：用問題開頭（「你知唔知腰痛嘅真正原因？」）
- 加粵語字幕（用CapCut自動字幕功能）
- 時長30-60秒最佳
- 配輕鬆背景音樂

### 小紅書內容策略

小紅書用戶特點：**主動搜索健康資訊**，所以要優化標題同關鍵字。

| 內容類型 | 頻率 | 標題風格 |
|----------|------|----------|
| 痛症知識 | 每週1篇 | 「腰痛3年終於好了！中醫針灸真的有用嗎？」 |

| 穴位教學 | 每2週1篇 | 「失眠按呢個穴位！30秒即刻放鬆」 |

### 小紅書標題公式

```
[痛點/問題] + [解決方案] + [效果/結果]

範例：
❌ 「分享一下頸痛嘅治療方法」（太平淡）
✅ 「頸痛到瞓唔到？中醫教你3招即時紓緩！」（有吸引力）

### 建議每週排程

| 星期 | 平台 | 內容類型 | 時間 |
|------|------|----------|------|
| 一 | Facebook | 痛症知識圖文 | 12:00 |
| 二 | - | 休息 / 準備素材 | - |
| 三 | Instagram | Reels短片 | 20:00 |

| 六 | Facebook + IG | 互動帖/Story | 10:00 |

### 每週工作流程

1. **星期日（1小時）**：規劃下週內容、準備文字
2. **星期一（30分鐘）**：用Canva設計Facebook帖文，發佈
3. **星期二（45分鐘）**：拍攝Reels短片素材
4. **星期三（30分鐘）**：剪輯短片（CapCut），發佈到IG
5. **星期四（20分鐘）**：發佈Facebook帖文
6. **星期五（20分鐘）**：改編內容發佈到小紅書
7. **星期六（15分鐘）**：發Story/互動帖

| 用途 | 顏色 | 色碼 |

### 設計原則

- 字體要大（照顧長者閱讀）
- 圖片清晰明亮
- 風格統一（用Canva模板）
- 保持中醫「自然、溫暖」嘅感覺
- 每張圖加診所名/logo水印

### Canva模板建議

1. 建立一個診所品牌模板（Brand Kit）
2. 固定使用2-3種模板排版
3. 痛症知識用一種版面，養生用另一種
4. 保持視覺一致性

## 互動策略

### 回覆留言原則

- **15分鐘內回覆**（如果可以）
- 用親切、專業嘅語氣
- 避免在公開留言診斷病情
- 引導到WhatsApp或到診所諮詢

### 回覆範例

```
留言：「我腰痛咗好耐，針灸有冇用？」

回覆：「你好！腰痛好常見，針灸對好多類型嘅腰痛都有好好嘅效果。
不過每個人嘅情況唔同，建議先嚟診所做個檢查，醫生可以根據你嘅
情況制定最適合嘅治療方案。歡迎WhatsApp預約：9XXX XXXX 😊」

## 注意事項

### 法律合規

1. **唔好作出療效保證**：避免用「保證根治」、「一次見效」等字眼
2. **病人相片需獲書面同意**：拍攝治療過程前必須獲得書面授權
3. **遵守中醫藥管理委員會規定**：廣告內容需符合相關法規
4. **避免比較**：唔好與其他醫生或診所比較

### 內容禁忌

- 不建議公開處方或藥方
- 避免過於醫學化嘅術語（用通俗語言）
- 唔好回應負面評論時情緒化
- 避免涉及政治或爭議性話題
