# 內容行銷策略

## 核心理念

**「用專業知識吸引病人，而唔係用廣告推銷」**

透過分享實用嘅中醫健康知識，建立信任，令街坊覺得呢位醫生值得信賴，自然會嚟睇。

## 內容製作流程

### 圖文帖文製作流程（30分鐘/篇）

```
1. 選擇主題（5分鐘）
   ↓
2. 撰寫文字內容（10分鐘）
   ↓
3. 用Canva設計配圖（10分鐘）
   ↓
4. 加入hashtags（2分鐘）
   ↓
5. 發佈 + 分享到群組（3分鐘）
```

### 短片製作流程（45-60分鐘/條）

```
1. 確定主題及重點（5分鐘）
   ↓
2. 寫簡單腳本/要點（5分鐘）
   ↓
3. 拍攝素材（15-20分鐘）
   ↓
4. CapCut剪輯 + 加字幕（15-20分鐘）
   ↓
5. 選配樂 + 最終檢查（5分鐘）
   ↓
6. 發佈到IG Reels / Facebook / 小紅書（5分鐘）
```

## 內容回收策略（一魚多吃）

一篇內容可以改編成多個平台嘅帖文：

```
一篇「腰痛穴位」內容 →

Facebook：完整圖文帖（500字 + Canva設計圖）
    ↓
Instagram Reels：30秒穴位示範短片
    ↓
IG Story：投票「你有冇腰痛問題？」
    ↓
小紅書：改編成筆記格式（加小紅書風格標題）
    ↓
Google Post：精簡版（150字）
    ↓
WhatsApp廣播：摘要版 + 連結
```

呢個方法可以大幅減少內容製作時間，一份素材用盡所有平台。
