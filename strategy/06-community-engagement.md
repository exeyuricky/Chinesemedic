# 社區互動策略（公屋區特色）

## 公屋區社區特點

公屋區嘅社區有幾個重要特點影響營銷策略：

| 特點 | 對策 |
|------|------|
| 鄰里關係密切 | 口碑傳播速度快，要維護好每一位病人 |
| 長者比例高 | 內容要易懂、字體要大、語言要親切 |
| 價格敏感 | 強調性價比、中醫醫療券 |
| 信任建基於熟悉感 | 參與社區活動建立「街坊」形象 |
| 集中居住 | 容易透過社區設施觸及大量居民 |

---

## 策略一：免費健康講座（每季一次）

### 與長者中心/社區中心合作

**目標**：每季度舉辦一次免費健康講座，建立專業形象同社區知名度。

#### 聯絡流程

```
1. 搵出區內長者中心/社區中心名單
   ↓
2. 致電或親自拜訪負責人
   ↓
3. 提出合作建議：免費健康講座
   ↓
4. 確定日期、時間、主題
   ↓
5. 設計海報（Canva）、準備講義
   ↓
6. 舉辦講座
   ↓
7. 拍攝花絮發佈到社交媒體
   ↓
8. 收集參加者聯絡方式（有興趣者）
```

#### 講座主題建議

| 季度 | 主題 | 內容重點 | 時長 |
|------|------|----------|------|
| Q1（春） | 「春天濕重點算好？中醫教你祛濕養生」 | 祛濕方法、穴位教學、湯水推介 | 45分鐘 |
| Q2（夏） | 「夏天保健：預防中暑同關節痛」 | 消暑方法、夏天常見病症預防 | 45分鐘 |
| Q3（秋） | 「秋冬養生：保護關節同腰膝」 | 關節保養、秋冬進補建議 | 45分鐘 |
| Q4（冬） | 「冬天痛症特別多？教你預防同紓緩」 | 冬天常見痛症、保暖方法 | 45分鐘 |

#### 講座流程範本（45分鐘）

```
0:00 - 0:05  自我介紹、診所簡介
0:05 - 0:25  主題講解（用簡單語言、配圖片）
0:25 - 0:35  實用示範（穴位按壓教學）
0:35 - 0:45  問答環節
結束後       派發健康小冊子 + 診所名片
```

#### 講座物料清單

- [ ] 海報（Canva設計，A3大小）
- [ ] 講義/健康小冊子（A4，Canva設計）
- [ ] 診所名片/轉介卡
- [ ] 簡報/圖片（如有投影設備）
- [ ] 養生茶包（送參加者）

## 策略二：屋邨內宣傳

### 管理處佈告欄

- 向屋邨管理處申請張貼海報
- 海報設計要清晰：大字體、簡潔、包含二維碼
- 每季更新一次海報內容

內容：

- 定期更新內容（配合節氣/季節）
- 小冊子主題：穴位圖解、養生湯水食譜、常見痛症Q&A

## 策略三：與區內商戶合作

### 互相轉介網絡

| 合作對象 | 合作方式 |
|----------|----------|
| 附近藥房 | 互放名片、遇到適合中醫治療嘅病人互相轉介 |
| 物理治療中心 | 互補不足：中醫處理某類痛症，西醫物理治療處理另一類 |
| 涼茶舖 | 放置診所名片、互相推薦 |
| 區內診所（西醫） | 中西醫結合轉介 |
| 跌打館 | 如有互補嘅服務可以合作 |
| 附近理髮店/美容院 | 放置診所名片（閒聊時容易提到健康） |

### 合作洽談話術

```
「你好，我係[屋邨名稱]中醫診所嘅[名字]，我爸爸係呢度嘅中醫師。
我見到你嘅[商店名]好受街坊歡迎，想同你傾下有冇合作嘅機會。

我哋可以互相放對方嘅名片，如果你嘅客人有痛症或者想睇中醫，
你可以介紹佢哋過嚟，我哋都會介紹客人幫襯你。

唔知你有冇興趣？」
```

## 策略四：社區活動參與

### 屋邨活動機會

| 活動類型 | 參與方式 | 頻率 |
|----------|----------|------|
| 屋邨嘉年華 | 申請擺攤（免費健康檢查/諮詢） | 如有活動 |
| 長者活動日 | 提供免費穴位按壓體驗 | 如受邀 |

| 節日活動 | 派發應節養生小貼士 | 節日前 |

### 攤位設置建議（如有機會擺攤）

| 項目 | 說明 |
|------|------|
| Banner | 診所名稱 + 服務（可用易拉架） |
| 免費服務 | 簡單穴位按壓體驗（5分鐘/人） |
| 派發物 | 健康小冊子 + 診所名片 + 轉介卡 |
| 收集資料 | 有興趣者留低WhatsApp（需同意） |
| 拍攝 | 攤位花絮相片/短片發佈社交媒體 |

## 成效衡量

| 指標 | 追蹤方法 |
|------|----------|
| 講座參加人數 | 現場記錄 |
| 講座後到診人數 | 問新病人「點樣知道我哋」 |
| 轉介合作帶來嘅病人 | 記錄轉介來源 |
| 社區活動觸及人數 | 現場估算 + 社交媒體觸及 |

**重要提醒**：所有社區互動嘅目標係建立「街坊信任」，唔係直接推銷。以幫助人嘅心態去做，效果會更好。
