# Google 商戶檔案（Google Business Profile）優化策略

## 點解Google Business Profile係第一步？

Google Business Profile (GBP) 係免費嘅，而且係大部分人搵中醫嘅第一個接觸點。當有人喺Google搜索「附近中醫」、「[區名]中醫」或者「痛症中醫」嘅時候，GBP會直接顯示你嘅診所資訊、評價、相片同埋聯絡方式。

**你依家已經有Google Maps listing，只需要優化佢就可以即時提升曝光。**

---

## 第一步：完善基本資料（1小時）

### 1.1 認領及驗證Google Business Profile

如果你未認領（claimed）你嘅GBP，需要先做呢個步驟：

1. 前往 Google Business Profile Manager
2. 搜索你嘅診所名稱
3. 點擊「認領此商戶」
4. 透過電話或明信片驗證

### 1.2 填寫所有欄位

以下每個欄位都要填寫完整：

| 欄位 | 填寫指引 | 範例 |
|------|----------|------|
| 商戶名稱 | 正式註冊名稱 | [診所名稱] 中醫診所 |
| 類別 | 主要：中醫診所；次要：針灸診所 | Chinese Medicine Clinic |
| 地址 | 完整地址包括樓層及室號 | [屋邨名稱] [座數] 地下 [舖位] |
| 電話 | 診所固定電話 | 2XXX XXXX |
| WhatsApp | 加入WhatsApp按鈕 | 9XXX XXXX |
| 網站 | 之後加Google Sites連結 | - |
| 營業時間 | 精確到每日 | 週一至六 10:00-19:00 |
| 特別營業時間 | 公眾假期 | 農曆新年休息 |

### 1.3 撰寫商戶描述（750字以內）

描述要包含以下關鍵字（自然植入，唔好堆砌）：

**必須包含嘅關鍵字**：
- 痛症治療
- 針灸
- 推拿
- 中醫
- [區名]
- 腰痛 / 頸痛 / 肩周炎

**範例描述**：

```
[診所名稱]位於[區名][屋邨名稱]，為區內街坊提供專業中醫診療服務超過三年。

本診所由註冊中醫師[醫生姓名]主理，專長痛症治療，包括腰痛、頸痛、肩周炎、膝蓋痛、坐骨神經痛等常見痛症。透過針灸、推拿、拔罐等傳統中醫療法，配合中藥處方，為病人提供全面嘅治療方案。

除痛症外，本診所亦提供全科中醫服務，包括內科、婦科調理、感冒咳嗽、腸胃不適、失眠等常見病症。

本診所位於[屋邨名稱]，交通方便，鄰近[港鐵站/巴士站]，服務[區名]及鄰近社區居民。歡迎致電或WhatsApp預約。
```

## 第二步：上載高質素相片（30分鐘）

### 2.1 必須上載嘅相片類型

| 相片類型 | 數量 | 拍攝建議 |
|----------|------|----------|
| 診所外觀 | 2-3張 | 要見到招牌，日間拍攝 |
| 診所內部 | 3-4張 | 整潔明亮，展示治療環境 |
| 治療設備 | 2-3張 | 針灸針、艾灸設備、拔罐等 |
| 醫生工作照 | 2-3張 | 穿白袍、專業形象 |
| 中藥房/藥材 | 1-2張 | 展示中藥材（如有） |

### 2.2 拍攝貼士

- 用自然光，避免閃光燈
- 確保環境整潔
- 橫拍為主（Google展示效果較好）
- 可以用Canva加少量文字標註
- 每月更新1-2張新相片

## 第三步：每週發布Google Post（每週15分鐘）

### 3.1 Google Post類型

| 類型 | 頻率 | 內容 |
|------|------|------|
| 最新消息 | 每週1次 | 健康小貼士、節氣養生 |
| 優惠 | 偶爾 | 新症優惠（如有） |
| 活動 | 按需 | 健康講座、社區活動 |

### 3.2 Google Post範例

**範例1：痛症知識**
```

試下按壓呢3個穴位，每個穴位按30秒：

1️⃣ 委中穴 - 膝蓋後面正中
2️⃣ 腎俞穴 - 腰部兩側
3️⃣ 大腸俞穴 - 腰部下方

如果腰痛持續，建議睇中醫做針灸治療，效果更好。

📞 預約：2XXX XXXX
📱 WhatsApp：9XXX XXXX
```

**範例2：節氣養生**

## 第四步：設定聯絡方式（15分鐘）

### 4.1 啟用WhatsApp按鈕

1. 進入GBP管理後台
2. 點擊「訊息」
3. 設定WhatsApp Business號碼
4. 開啟「接受訊息」功能

### 4.2 設定預約連結

- 如果用WhatsApp預約：將WhatsApp連結設為預約URL
- 格式：`https://wa.me/852XXXXXXXX?text=你好，我想預約睇中醫`

## 常見問題

**Q：要幾耐先見到效果？**
A：完善GBP後通常2-4週就會開始見到搜索量提升。

**Q：競爭對手好多點算？**
A：保持定期更新、回覆評價、上載相片，Google會優先展示活躍嘅商戶。

**Q：可唔可以自己修改Google Maps上嘅位置？**
A：可以，認領GBP後就可以修改所有資訊，包括位置標記。
