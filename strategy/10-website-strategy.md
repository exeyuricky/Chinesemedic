# Google Sites 免費網站建設策略

## 點解要有網站？

雖然Google Business Profile同Facebook專頁已經好有用，但擁有自己嘅網站有以下好處：

| 好處 | 說明 |
|------|------|
| 提升專業形象 | 有獨立網站感覺更正式、更可信 |
| 本地SEO加分 | Google會優先顯示有網站嘅商戶 |
| 一站式資訊 | 病人可以一次過睇晒所有服務、地址、聯絡方式 |
| 零成本 | Google Sites完全免費 |
| 易於管理 | 拖放式編輯，唔需要技術背景 |
| 手機適配 | 自動適配手機及平板 |

## 第二部分：Google Sites建站步驟

### 步驟一：建立網站（15分鐘）

1. 前往 **sites.google.com**
2. 用診所Google帳號登入（同GBP同一個帳號）
3. 點擊 **「+」** 建立新網站
4. 選擇空白範本或健康相關範本

### 步驟二：網站命名

1. 網站名稱：`[診所名稱]中醫診所`
2. 頁首標題：`[診所名稱] - [區名]社區中醫診所`
3. 左上角logo：上載診所logo（可用Canva製作）

### 步驟三：設定網址

免費網址格式：`sites.google.com/view/your-clinic-name`

設定建議：
- 使用英文 + 診所名稱
- 例如：`sites.google.com/view/xxx-tcm-clinic`
- 盡量簡短易記

### 步驟四：選擇主題

Google Sites提供多個內建主題：
- **推薦**：「印象」（Impression）或「簡約」（Simple）
- 顏色：選擇綠色系（配合中醫形象）
- 字體：選擇易讀嘅中文字體

### 內容搬遷流程

#### 方法一：直接複製貼上（最簡單）

1. 打開對應嘅markdown檔案
2. 複製需要嘅內容
3. 喺Google Sites點擊「插入」→「文字框」
4. 貼上內容
5. 用Google Sites嘅格式工具調整外觀

#### 方法二：將markdown轉換為網頁格式

Markdown嘅表格、標題會變成純文字，需要重新格式化：

**原markdown**：
```markdown
## 痛症治療

專治各類常見痛症：
- 腰痛
- 頸痛
```

**喺Google Sites**：
1. 輸入「痛症治療」→ 設為「標題 2」
2. 輸入內容文字
3. 選擇項目符號列表（Bullet list）
4. 輸入：腰痛、頸痛等

#### 方法三：用AI工具輔助（進階）

可以叫ChatGPT/Claude幫你將markdown轉換為HTML，再貼到Google Sites嘅HTML嵌入元件。

## 進階技巧

### 嵌入Google評價

1. 喺Google Sites插入 → 嵌入
2. 使用 Google Reviews Widget（例如：Elfsight，有免費方案）
3. 或者截圖好評直接顯示

### 加入預約表格

使用Google Forms建立預約表格：
1. Google Forms建立：姓名、電話、預約日期、主訴
2. 喺Google Sites嵌入表格
3. 收到預約後用WhatsApp確認

### 加入健康文章訂閱

雖然Google Sites本身冇電郵功能，但可以：
- 放置「Follow我哋Facebook專頁」按鈕
- 放置「加入WhatsApp廣播列表」按鈕（連結到WhatsApp）
