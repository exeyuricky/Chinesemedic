# 轉介計劃（Referral Program）

## 核心理念

**公屋區最強嘅營銷渠道就係街坊之間嘅口碑。** 

轉介計劃就係將自然嘅口碑系統化，鼓勵滿意嘅病人介紹親友過嚟。

---

## 轉介獎勵方案

### 方案設計

```
舊病人介紹新病人
     ↓
新病人到診所完成首次治療
     ↓
舊病人 → 獲得養生茶包1份
新病人 → 獲得養生茶包1份
```

### 獎勵選擇（零/低成本）

| 獎勵 | 成本 | 說明 |
|------|------|------|
| 養生茶包 | 極低 | 用診所現有中藥材（紅棗、杞子、菊花等）自製 |
| 艾灸體驗 | 零 | 首次體驗艾灸（附加在正常治療上） |
| 健康小冊子 | 極低 | 自己用Canva設計印刷 |
| 中藥材小禮包 | 低 | 小包裝常見藥材（紅棗、杞子） |

### 養生茶包製作建議

用診所現有藥材，每包成本約$2-5：

| 茶包名稱 | 材料 | 功效 | 季節 |
|----------|------|------|------|
| 明目養肝茶 | 杞子、菊花、決明子 | 護眼明目 | 春天 |
| 祛濕健脾茶 | 薏米、茯苓、陳皮 | 祛濕 | 春夏 |
| 消暑茶 | 菊花、金銀花、甘草 | 清熱解暑 | 夏天 |
| 潤肺茶 | 羅漢果、菊花、甘草 | 潤肺止咳 | 秋天 |
| 暖身茶 | 紅棗、桂圓、薑片 | 驅寒暖身 | 冬天 |

## 轉介卡設計

### 設計規格

| 項目 | 建議 |
|------|------|
| 尺寸 | 名片大小（90mm x 54mm） |
| 工具 | Canva免費版 |
| 印刷 | 自己印 / 附近影印舖（每張約$0.5-1） |
| 數量 | 首批50-100張 |

### 轉介卡內容

**正面**：
```
┌─────────────────────────────────┐
│                                 │
│   [診所名稱] 中醫診所            │
│                                 │
│   📱 好友推薦卡                  │
│                                 │
│   憑此卡首次到診                 │
│   即送養生茶包一份               │
│                                 │
│   推薦人：___________            │
│                                 │
└─────────────────────────────────┘
```

**背面**：
```
┌─────────────────────────────────┐
│                                 │
│  💪 專治痛症 | 針灸推拿 | 中藥   │
│                                 │
│  📞 電話：2XXX XXXX             │
│  📱 WhatsApp：9XXX XXXX         │
│  📍 [完整地址]                   │
│  ⏰ 週一至六 10:00-19:00        │
│                                 │
│  [QR Code - WhatsApp連結]       │
│                                 │
└─────────────────────────────────┘
```

### Canva設計步驟

1. 打開Canva，搜索「名片」模板
2. 選擇簡潔設計嘅模板
3. 修改文字及顏色（用診所品牌色）
4. 加入QR Code（可用免費QR Code生成器）
5. 下載PDF（適合印刷）
6. 喺附近影印舖印刷

## 執行流程

### 日常流程

```
病人完成治療
    ↓
醫生：「今日治療效果點？覺得有改善嗎？」
    ↓
病人回應正面
    ↓
你/醫生：「好開心聽到！我哋有個街坊推薦計劃，
如果你身邊有朋友或家人有痛症困擾，可以介紹
佢哋嚟試下。送你幾張推薦卡，介紹一個新病人
嚟，你同佢都會收到我哋嘅養生茶包 🍵」
    ↓
遞上2-3張轉介卡
    ↓
新病人攜帶轉介卡到診
    ↓
記錄推薦人資訊
    ↓
下次舊病人覆診時送上養生茶包
```

### 追蹤方法（簡單版）

用一本筆記簿記錄：

| 日期 | 推薦人 | 新病人 | 獎勵已送 |
|------|--------|--------|----------|
| 4/8 | 陳太太 | 李先生 | ✅ |
| 4/15 | 王伯伯 | 張太太 | ⬜ |

## WhatsApp轉發策略

### 製作易轉發嘅健康資訊圖片

設計一系列「健康小卡」，街坊會主動轉發到WhatsApp群：

| 類型 | 範例 | 設計要點 |
|------|------|----------|
| 穴位圖 | 「按呢個穴位紓緩頭痛」 | 清晰穴位位置圖 + 簡單說明 |
| 養生提醒 | 「明天立秋，記得食呢3種食物」 | 食物圖片 + 簡短文字 |
| 天氣健康 | 「翻風落雨關節痛？試下呢個方法」 | 實用建議 + 診所資訊 |

**設計關鍵**：
- 圖片底部小小加上診所名稱及WhatsApp號碼
- 唔好太像廣告（自然分享感）
- 內容實用（令人想轉發畀朋友）
- 尺寸：1080 x 1080（正方形，適合WhatsApp）

## 成效追蹤

### 每月統計

| 指標 | 目標（首月） | 目標（第6個月） |
|------|-------------|----------------|
| 派出轉介卡 | 20張 | 50張/月 |
| 轉介新病人 | 2-3人 | 5-8人/月 |
| 轉介成功率 | 10-15% | 15-20% |
| 茶包送出 | 4-6份 | 10-16份 |

### 優化建議

- 如果轉介率低：考慮提升獎勵或簡化流程
- 如果特定病人介紹好多人：特別感謝佢，考慮額外獎勵
- 定期更換茶包口味/類型，保持新鮮感
- 節日期間可以推出「節日特別版」轉介獎勵
