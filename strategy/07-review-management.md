# Google 評價管理策略

## 點解Google評價咁重要？

1. **影響搜索排名**：評價越多、分數越高，Google越優先展示你
2. **影響決策**：超過80%嘅人會睇Google評價先決定去唔去
3. **免費廣告**：好評就係最有說服力嘅廣告
4. **SEO加分**：評價中嘅關鍵字會幫助搜索排名

---

## 目標

| 時間 | 目標 |
|------|------|
| 第1-2個月 | 累積10個評價，平均4.5星以上 |
| 第3-4個月 | 累積20個評價 |
| 第5-6個月 | 累積30+個評價 |
| 持續 | 每月新增3-5個評價 |

## 步驟一：製作Google評價QR Code

### 獲取Google評價連結

1. 打開Google Business Profile管理後台
2. 點擊「獲取更多評價」或「分享評論表單」
3. 複製評價連結（短網址）

### 製作QR Code

1. 前往免費QR Code生成器（如 QR Code Generator）
2. 貼上Google評價連結
3. 生成QR Code
4. 下載PNG圖片

### 製作前台企牌（Canva）

```
尺寸：A5（148 x 210 mm）或明信片大小

設計內容：

│                          │

│   請幫手喺Google           │
│   寫個評價 🙏              │
│                          │
│      [QR Code]           │
│                          │
│   用手機掃描即可評價       │
│                          │

```

### 放置位置

- 前台/收銀台（最顯眼位置）
- 等候區
- 治療室門口

## 步驟二：建立評價邀請流程

### 最佳邀請時機

| 時機 | 效果 | 方法 |
|------|------|------|
| 治療後即時（最佳） | ⭐⭐⭐⭐⭐ | 口頭邀請 + 指向QR Code |
| 治療後當日 | ⭐⭐⭐⭐ | WhatsApp發送評價連結 |
| 覆診前一日 | ⭐⭐⭐ | WhatsApp提醒時附上連結 |
| 療程完成後 | ⭐⭐⭐⭐ | WhatsApp感謝 + 邀請評價 |

### 口頭邀請話術（粵語）

**情景一：治療效果好**
```
醫生：「今日感覺點？有冇好啲？」
病人：「好咗好多！」
醫生/你：「太好喇！好開心聽到。如果你方便嘅話，
可唔可以幫我哋喺Google寫個評價？前面有個QR Code，
掃一掃就得㗎喇。你嘅評價會幫到其他有類似問題嘅
街坊搵到我哋 🙏」
```

**情景二：療程完成**
```
醫生/你：「恭喜你完成咗療程！睇返你嘅進展真係
好大改善。如果你覺得我哋嘅治療有幫到你，可唔可以
幫手喺Google寫幾隻字？你嘅真實分享對其他
有需要嘅街坊好有參考價值。」
```

**重要原則**：
- 只喺病人表達正面回饋時才邀請
- 唔好施壓或者強迫
- 用「幫到其他人」嘅角度邀請（唔係「幫我」）
- 如果病人唔方便或者唔想，唔好再追問

## 步驟三：回覆所有評價

### 回覆原則

| 規則 | 說明 |
|------|------|
| 時效 | 24-48小時內回覆 |
| 正面評價 | 真誠感謝、個人化回覆 |
| 負面評價 | 專業、冷靜、不爭辯 |
| 每條都覆 | 100%回覆率 |

### 正面評價回覆範本

**5星評價回覆**：
```
範本A：
「多謝[稱呼]嘅好評！好開心我哋嘅治療幫到你，
祝你身體越來越好！如有任何需要歡迎隨時預約。🙏」

範本B：
「感謝你嘅分享！你嘅信任係我哋最大嘅動力。
希望你嘅[痛症名]持續改善，有任何問題隨時搵我哋。」

範本C：
「非常感謝你撥冗寫評價！作為社區中醫診所，
街坊嘅認可係我哋最大嘅鼓勵。祝身體健康！」
```

### 負面評價回覆範本

**處理原則**：
1. 深呼吸，冷靜回應
2. 先道歉，表達關注
3. 提出解決方案
4. 引導到線下溝通

```
範本：
「感謝你嘅反饋，我哋非常重視每一位病人嘅體驗。
對於你提到嘅[問題]，我哋深感抱歉。
麻煩你WhatsApp我哋（9XXX XXXX），
我哋希望可以了解詳情並作出改善。
你嘅意見會幫助我哋提供更好嘅服務。」
```

**絕對唔好做**：
- ❌ 喺回覆中爭辯
- ❌ 透露病人私隱
- ❌ 指責病人
- ❌ 置之不理

### 社交媒體分享（需病人同意）

- 截圖好評，分享到Facebook/Instagram
- 遮蓋病人真實姓名（如未獲同意使用全名）
- 配文：「多謝街坊嘅支持同信任！」

## 常見問題

**Q：如果有人寫假嘅負面評價點算？**
A：可以向Google舉報虛假評價。同時寫一個專業嘅回覆，讓其他讀者看到你嘅態度。

**Q：可唔可以畀錢買評價？**
A：絕對唔好！Google會偵測到虛假評價，可能會懲罰你嘅帳號。真實嘅評價先係最有效嘅。

**Q：點先知道有新評價？**
A：Google Business Profile app會發推送通知。建議開啟通知功能。

**Q：病人唔識用Google寫評價點算？**
A：耐心教佢哋用手機掃描QR Code，或者幫佢哋打開評價頁面。長者可能需要多啲指導。
