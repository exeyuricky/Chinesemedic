# 本地SEO優化策略

## 什麼是本地SEO？

當有人喺Google搜索「附近中醫」、「[區名]針灸」或者「痛症中醫」嘅時候，Google會優先顯示附近嘅商戶。本地SEO就係令你嘅診所喺呢啲搜索結果中排得更前嘅方法。

**零預算就可以做到，而且效果持久。**

## 行動計劃

### 步驟一：Google Business Profile 優化（最重要）

GBP係本地SEO最重要嘅因素。詳細做法參考 [01-google-business-profile.md](01-google-business-profile.md)。

**關鍵SEO動作**：
1. 商戶名稱用全名：「[診所名稱] - [區名]中醫診所」
2. 類別設定正確：主要類別「中醫診所」，次要「針灸診所」
3. 描述中自然植入目標關鍵字
4. 每週發Google Post（含關鍵字）
5. 定期上載新相片（Google偏好活躍商戶）

### 步驟二：免費目錄登記（初始2小時）

喺以下免費平台登記你嘅診所資訊：

| 平台 | 類型 | 行動 |
|------|------|------|
| Google Business Profile | 搜索引擎 | 完善所有資訊（已做） |
| 香港中醫藥管理委員會 | 官方目錄 | 確認已列入註冊中醫名冊 |
| 開飯喇 OpenRice | 生活平台 | 部分有醫療健康分類 |
| 28Hse / 社區資訊網站 | 社區平台 | 登記商戶資訊 |
| Facebook Places | 社交平台 | 設定專頁地點 |
| Yelp Hong Kong | 評價平台 | 建立商戶檔案 |
| HKdecoman / 裝修佬 | 社區網 | 如有社區版面可登記 |

**重要**：所有平台嘅資訊必須一致（名稱、地址、電話），呢個叫做 NAP 一致性（Name, Address, Phone）。

### 步驟三：建立Google Sites網站（提升SEO）

擁有一個網站可以大幅提升本地搜索排名。詳細做法參考 [10-website-strategy.md](10-website-strategy.md)。

**網站SEO基本做法**：
1. 每頁標題包含目標關鍵字
2. 撰寫各服務嘅詳細描述（每頁300-500字）
3. 加入地址及Google地圖
4. 連結到Google Business Profile
5. 每月更新1篇健康文章

### 步驟四：獲取Google評價（含關鍵字）

Google評價唔單止影響信任度，仲會影響搜索排名。

**引導病人在評價中提及**：
- 治療類型：「針灸治療腰痛好有效」
- 地區名：「[區名]最好嘅中醫」
- 服務體驗：「推拿好舒服，頸痛即時好咗」

**引導話術**：
```
「多謝你對我哋嘅信任！如果方便嘅話，可唔可以幫我哋喺Google
寫個評價？如果可以提到你做咗咩治療同埋效果，會幫到其他
有類似問題嘅街坊搵到我哋 🙏」
```

### 步驟五：社交媒體SEO

雖然社交媒體帖文唔直接影響Google排名，但係：
- Facebook專頁會出現喺Google搜索結果
- 社交媒體帖文可以被Google收錄
- 增加品牌搜索量（有人搜你診所名）

**做法**：
- Facebook專頁名稱包含「[區名]中醫」
- 帖文標題包含目標關鍵字
- 小紅書筆記標題包含搜索關鍵字

## 監測及調整

### 免費監測工具

| 工具 | 用途 | 檢查頻率 |
|------|------|----------|
| Google Business Profile Insights | 搜索量、點擊量、來電量 | 每月1次 |
| Facebook Page Insights | 帖文觸及率、專頁互動 | 每週1次 |
| Google Search Console | 網站搜索排名（需有網站） | 每月1次 |

### 每月SEO檢查清單

- [ ] 檢查GBP Insights數據（搜索量趨勢）
- [ ] 確認所有目錄資訊正確一致
- [ ] 發佈至少4篇含關鍵字嘅Google Post
- [ ] 回覆所有Google評價
- [ ] 更新網站內容（如有）
- [ ] 檢查有冇新嘅負面評價需要處理

## 預期效果

| 時間 | 預期結果 |
|------|----------|
| 第1個月 | GBP完善，開始出現喺搜索結果 |
| 第2-3個月 | 搜索量逐步提升，Google Post帶來曝光 |
| 第4-6個月 | 評價累積，搜索排名穩定提升 |
| 6個月後 | 穩定出現喺「[區名]中醫」搜索前列 |

**注意**：SEO係長期工作，需要持續進行，唔會一夜之間見到效果，但一旦建立起來，效果會持久。
