# WhatsApp 通訊策略

## 點解WhatsApp係香港最重要嘅溝通工具？

香港超過90%嘅人用WhatsApp，係日常溝通嘅首選。對於診所嚟講，WhatsApp係：
- 預約渠道
- 病人跟進工具
- 健康資訊推廣渠道
- 客戶關係管理工具

---

## 第一步：設定WhatsApp Business（1小時）

### 下載及設定

1. 喺App Store / Google Play下載 **WhatsApp Business**（免費）
2. 用診所電話號碼註冊
3. 填寫商戶資料

### 必填商戶資料

| 欄位 | 內容 |
|------|------|
| 商戶名稱 | [診所名稱] 中醫診所 |
| 類別 | 醫療與健康 |
| 描述 | 簡短描述服務（100字以內） |
| 地址 | 完整診所地址 |
| 營業時間 | 週一至六 10:00-19:00 |
| 電郵 | 如有 |
| 網站 | Google Sites網站連結（之後加） |

### 商戶描述範例

```
[診所名稱] 位於[區名][屋邨名稱]，由註冊中醫師主理。
專治痛症（腰痛、頸痛、肩周炎），提供針灸、推拿、
拔罐、中藥處方等服務。歡迎WhatsApp預約！
```

## 第二步：設定自動回覆

### 離開訊息（非營業時間）

```
設定路徑：WhatsApp Business → 商業工具 → 離開訊息

離開訊息內容：
「你好！感謝你嘅查詢。

我哋嘅營業時間係：
📅 週一至六 10:00-19:00
🚫 週日及公眾假期休息

我哋會喺營業時間內盡快回覆你。
如需緊急預約，請致電：2XXX XXXX

[診所名稱] 中醫診所 🏥」
```

### 問候訊息（首次聯繫）

```
設定路徑：WhatsApp Business → 商業工具 → 問候訊息

問候訊息內容：
「你好！歡迎查詢 [診所名稱] 中醫診所 🏥

我哋可以幫到你：
💪 痛症治療（腰痛、頸痛、肩周炎等）
🔧 針灸 · 推拿 · 拔罐 · 中藥處方
🩺 全科中醫

請問你想：
1️⃣ 預約睇診
2️⃣ 查詢服務
3️⃣ 查詢營業時間/地址

直接回覆數字或者你嘅問題，我哋會盡快回覆！」
```

### 快速回覆設定

| 快捷鍵 | 訊息內容 | 使用場景 |
|--------|----------|----------|
| /confirm | 預約確認模板 | 確認預約 |
| /remind | 覆診提醒模板 | 覆診前一日 |
| /thanks | 治療後感謝 | 治療完成後 |
| /address | 地址及交通指引 | 回覆問路 |
| /hours | 營業時間 | 回覆查詢營業時間 |
| /review | 評價邀請 | 邀請寫Google評價 |

詳細模板內容參考 [病人通訊模板](../templates/patient-messages.md)

## 第三步：WhatsApp目錄設定

### 建立服務目錄

```
設定路徑：WhatsApp Business → 商業工具 → 目錄

建議加入嘅服務項目：
```

| 服務名稱 | 描述 | 價格 |
|----------|------|------|
| 痛症治療（針灸） | 針灸治療各類痛症 | 可寫價格或「歡迎查詢」 |
| 推拿治療 | 中醫推拿紓緩肌肉痛症 | 同上 |
| 拔罐治療 | 傳統拔罐祛濕活血 | 同上 |
| 全科中醫診症 | 內科、婦科等一般病症 | 同上 |
| 中藥處方 | 根據體質配製中藥 | 同上 |

## 第四步：日常通訊管理

### 預約流程

```
病人查詢
    ↓
「你好！想幫你預約，請問：
1. 你嘅姓名？
2. 想預約邊日邊個時間？
3. 主要係咩問題？（例如：腰痛、頸痛等）」
    ↓
確認預約
    ↓
「已幫你預約好：
📅 日期：X月X日（星期X）
⏰ 時間：XX:XX
📍 地址：[完整地址]

前一日我哋會再WhatsApp提醒你。
如需改期請提早通知。
期待為你服務！🙏」
    ↓
前一日發送覆診提醒
    ↓
治療後跟進（如適用）
```

### 每日WhatsApp管理（10分鐘）

| 時間 | 任務 |
|------|------|
| 早上開舖 | 檢查新訊息、回覆查詢 |
| 中午 | 回覆上午新訊息 |
| 收舖前 | 回覆下午新訊息、發送明日覆診提醒 |

## 第五步：WhatsApp廣播策略

### 建立廣播列表

**重要**：必須獲得病人同意先可以加入廣播列表。

```
建議話術：
「我哋每個月會透過WhatsApp分享1-2次健康資訊
同養生貼士，你有冇興趣收到呢？」
```

### 廣播頻率及內容

| 頻率 | 內容類型 | 說明 |
|------|----------|------|
| 每月2次 | 健康資訊 | 節氣養生、痛症預防貼士 |
| 按需 | 診所公告 | 營業時間變動、假期安排 |
| 節日 | 節日問候 | 農曆新年、中秋等問候 |

### 廣播訊息範例

**範例1：節氣養生**
```
🌿【清明養生小貼士】

清明時節天氣潮濕，容易：
😴 覺得攰、精神差
💪 關節痛加重
🤧 容易感冒

中醫建議：
1. 飲赤小豆薏米水祛濕
2. 按壓足三里穴增強免疫
3. 避免食生冷嘢

如有痛症或身體不適，歡迎預約諮詢 🏥
📱 直接回覆呢個訊息即可預約

[診所名稱] 中醫診所
祝各位身體健康！💪
```

**範例2：節日問候**
```
🧧 [診所名稱] 恭祝各位街坊

新年快樂！身體健康！龍馬精神！

🏥 新年營業安排：
年三十（X月X日）：營業至16:00
年初一至年初三：休息
年初四起：正常營業

如有需要，年初四後歡迎預約。
祝大家新年進步，萬事如意！🎊
```

## 第六步：WhatsApp Status（狀態）

### 善用WhatsApp Status發佈內容

WhatsApp Status就好似Instagram Story，你嘅聯絡人都會見到。

| 內容類型 | 頻率 | 範例 |
|----------|------|------|
| 健康小貼士 | 每週2-3次 | 穴位按壓圖、養生建議 |
| 診所日常 | 每週1次 | 診所環境、藥材 |
| 營業提醒 | 按需 | 假期安排、特別時間 |

**貼士**：呢啲Status可以直接用Facebook/IG嘅帖文改編，唔使額外製作。

## 通訊管理原則

### 回覆時效

| 類型 | 建議回覆時間 |
|------|-------------|
| 預約查詢 | 30分鐘內 |
| 一般查詢 | 2小時內 |
| 非營業時間 | 下個營業日開舖後 |

### 溝通語氣

- 親切但專業
- 用粵語口語（但唔好太隨便）
- 適當使用表情符號（唔好過多）
- 耐心回答長者嘅問題

### 私隱保護

- 唔好喺群組討論病人病情
- 唔好轉發病人嘅個人資訊
- 病人相片需獲書面同意先可使用
- 遵守個人資料（私隱）條例
