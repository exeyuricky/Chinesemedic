# 中醫診所網絡行銷策略

## 項目簡介

呢個係一份為**公屋區社區中醫診所**量身定制嘅零預算網絡行銷策略方案。目標係透過免費嘅數碼工具同社區互動，提升診所知名度，吸引鄰近5公里範圍內嘅新病人。

## 診所背景

| 項目 | 詳情 |
|------|------|
| 類型 | 社區中醫診所（一人診所） |
| 位置 | 香港公屋區 |
| 經營年期 | 3年以上 |
| 主打服務 | 痛症治療（腰痛、頸痛、肩周炎、膝蓋痛等） |
| 其他服務 | 全科中醫、針灸推拿、中藥處方 |
| 目標客群 | 5公里範圍內居民（長者、上班族、家庭主婦） |

## 團隊分工

- **醫生（父親）**：專注診症、治療、提供專業醫學內容
- **營銷負責人（子女）**：負責所有網上營銷工作，包括設計、拍片、社交媒體管理

## 現有資源

- Google Maps listing（已有）
- 設計能力（Canva等工具）
- 拍片剪輯能力（CapCut等工具）
- 彈性時間投入（每週5-8小時）
- 零營銷預算
