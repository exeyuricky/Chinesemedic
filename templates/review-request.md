# Google 評價邀請模板

呢個文件提供完整嘅Google評價收集系統，包括話術、QR Code設定、以及跟進流程。

---

## 評價收集全流程

```
1. 治療後口頭邀請（最有效）
   ↓
2. 前台QR Code企牌提醒
   ↓
3. WhatsApp跟進邀請
   ↓
4. 收到評價後回覆
   ↓
5. 好評分享到社交媒體（獲同意）
```

## 一、口頭邀請話術

### 何時邀請？（重要！）

**黃金時機**：
- ✅ 治療後病人表達正面感受
- ✅ 療程完成、病人感謝時
- ✅ 病人主動稱讚醫生/服務時
- ✅ 覆診時病人分享「好咗好多」

**避免邀請**：
- ❌ 病人第一次就診（未知效果）
- ❌ 病人表達不滿或有疑慮時
- ❌ 病人趕時間/情緒唔好時

## 三、評價引導話術（含關鍵字）

### 點解要引導關鍵字？

病人嘅評價內容會影響你嘅Google搜索排名。
如果評價中出現目標關鍵字（例如：「[區名]中醫」、
「腰痛針灸」、「痛症治療」），Google更容易
將你展示畀搜索呢啲關鍵字嘅人。

### 引導話術

#### 話術A：提示可以寫咩

```
「如果你想寫評價，可以考慮分享：
- 你係因為咩問題嚟睇？（腰痛/頸痛/...）
- 做咗咩治療？（針灸/推拿/...）
- 效果點樣？
- 對醫生/服務嘅感受

真實嘅分享最有幫助 😊」
```

#### 話術B：分享範例

```
「其他街坊嘅評價例如：
『我腰痛咗兩年，做咗6次針灸治療
後改善好多，[區名]有呢間中醫診所
真係唔錯！』

唔需要寫咁長，真實嘅就最好！」
```

## 四、QR Code企牌製作

### 獲取Google評價連結

#### 方法一：透過Google Business Profile

1. 登入 Google Business Profile Manager
2. 選擇你嘅商戶
3. 點擊「獲取更多評價」
4. 複製分享連結

#### 方法二：直接製作連結

```
連結格式：
https://g.page/r/[你嘅商戶ID]/review

商戶ID可以喺GBP後台找到
```

### 生成QR Code

**免費工具**：
1. QR Code Generator (qr-code-generator.com)
2. QR Tiger (qrtiger.com)
3. Canva內置QR功能

**生成步驟**：
1. 貼上Google評價連結
2. 選擇「URL」類型
3. 自訂顏色（可以用診所品牌色）
4. 加入logo（可選）
5. 下載高解析度PNG

### 企牌設計（Canva）

**尺寸**：A5（148 x 210 mm）

**設計佈局**：

```
┌────────────────────────────┐
│                            │
│    🌟 你嘅意見對我哋好重要！  │
│                            │
│                            │
│  如果你對今日嘅治療滿意     │
│  請幫手喺Google寫個評價     │
│                            │
│                            │
│       ┌──────────┐         │
│       │          │         │
│       │  [QR]    │         │
│       │  CODE    │         │
│       │          │         │
│       └──────────┘         │
│                            │
│     掃一掃 一分鐘完成       │
│                            │
│                            │
│    多謝你嘅支持！🙏          │
│                            │
│    [診所名稱]               │
│                            │
└────────────────────────────┘
```

**設計要點**：
- QR Code要大（至少5cm x 5cm）
- 背景純色，對比明顯
- 文字簡潔
- 加上診所logo

### 放置位置

| 位置 | 效果 |
|------|------|
| 前台/收銀台 | ⭐⭐⭐⭐⭐ 最顯眼 |
| 等候區枱面 | ⭐⭐⭐⭐ 病人等時間會睇到 |

## 八、常見問題

**Q1：病人唔識用Google點算？**
```
話術：「冇問題！我哋可以一齊做。
用你部手機掃呢個QR Code，會直接去
寫評價嘅頁面。你用自己嘅Google帳號
登入就寫到喇。如果冇Google帳號，
可以用Gmail帳號（如果有）都得！」
```

**Q2：病人話冇Gmail點算？**
```
話術：「冇問題！我哋完全明白。
其實用口頭同朋友介紹我哋都一樣咁有用！
有冇屋企人或者朋友有類似問題，
可以介紹佢哋過嚟試下？」
```

**Q3：點樣處理假嘅負面評價？**
- 舉報給Google（有明顯惡意 / 虛假）
- 同時寫一個專業、冷靜嘅回覆
- 讓其他讀者睇到你嘅態度
- 千祈唔好情緒化

**Q4：可唔可以畀錢買評價？**
- ❌ 絕對唔可以！
- Google會偵測並懲罰
- 甚至可能刪除商戶帳號
- 真實評價最有效、最安全

**Q5：幾耐會見到評價對生意嘅影響？**
- 累積到10+個評價：開始見到搜索排名改善
- 累積到20+個評價：明顯提升轉化率
- 平均分高於4.5：比競爭對手更有優勢
