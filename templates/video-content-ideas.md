# 短片內容企劃

短片係吸引新病人最有效嘅方法。呢個文件提供短片主題、腳本、拍攝及剪輯指南。

---

## 短片平台特性比較

| 平台 | 短片長度 | 比例 | 觀眾特性 |
|------|----------|------|----------|
| Instagram Reels | 15-90秒 | 9:16 直式 | 年輕、快節奏 |
| Facebook Reels | 15-90秒 | 9:16 直式 | 較廣泛年齡層 |
| YouTube Shorts | 最長60秒 | 9:16 直式 | 搜索導向 |
| 小紅書 | 最長5分鐘 | 9:16 / 16:9 | 健康養生向 |
| TikTok（可選） | 15秒-10分鐘 | 9:16 直式 | 年輕為主 |

**建議策略**：拍一條片，剪輯成不同長度發佈到多個平台。

## 完整腳本範例

### 範例一：穴位教學（45秒）

```
主題：按呢個穴位即刻紓緩頭痛！

【0:00-0:03 Hook（吸引3秒）】
醫生正面鏡頭，手指指住合谷穴
旁白：「頭痛？試下按呢個穴位！」

【0:03-0:10 問題點】
旁白：「都市人成日頭痛，成日食止痛藥？
其實中醫有個穴位可以快速紓緩！」

【0:10-0:25 穴位示範】
特寫鏡頭，醫生示範位置
旁白：「呢個叫合谷穴，喺拇指同食指之間
嘅虎口位置。」

展示位置圖解（CapCut加疊層）

【0:25-0:40 按壓方法】
醫生示範按壓
旁白：「用另一隻手嘅拇指，向食指骨頭方向
按壓30秒。力度要到感覺到痠脹為止。」

【0:40-0:45 結尾CTA】
醫生正面鏡頭
旁白：「兩邊手都做一次。如果頭痛持續，
建議搵中醫睇下。WhatsApp下面!」

字幕：📱 9XXX XXXX | [診所名稱][區名]中醫診所
```

### 範例二：痛症Q&A（60秒）

```

3️⃣ 腰椎退化 — 有承托力嘅床墊

【0:35-0:50 實用貼士】
醫生：「分享3個保護腰部嘅瞓姿：
✅ 側睡：膝蓋夾枕頭
✅ 仰睡：膝蓋下放枕頭

【0:50-0:60 結尾】
醫生：「如果腰痛持續，搵中醫做評估，
唔好自己拖！」

字幕：📱 WhatsApp諮詢：9XXX XXXX
```

## 拍攝指南

### 設備需求（零預算）

| 項目 | 推薦 | 備註 |
|------|------|------|
| 手機 | 現有智能手機 | 後置鏡頭畫質較好 |
| 手機架 | 三腳架 / 手機架 | 約$50-100（可選） |
| 光源 | 自然光 / 日光燈 | 避免逆光 |
| 收音 | 手機內置 | 近距離收音，注意背景雜音 |

### 拍攝環境

✅ **理想環境**：
- 診所內光線充足嘅區域
- 簡潔背景（避免雜亂）
- 安靜時段（例如早上開舖前）
- 可以見到少量診所元素（治療床、藥櫃）

❌ **避免**：
- 逆光（背後有窗）
- 雜亂背景
- 嘈雜環境
- 搖晃拍攝

### 構圖技巧

1. **直式9:16**：手機要轉直拍
2. **主角居中偏上**：頭頂留少少空間
3. **穴位特寫**：用橫屏拍細節，剪輯時裁切成直屏
4. **三分法**：醫生眼睛對準上三分之一線

### 拍攝流程

```
1. 寫好重點（唔需要逐字腳本）
   ↓
2. 試拍一次（測試收音、光線）
   ↓
3. 正式拍攝（多拍2-3個take）
   ↓
4. 拍穴位特寫/補充鏡頭（B-roll）
   ↓
5. 檢查錄得嘅片段
```

## CapCut剪輯教學

### 基本剪輯流程

```
1. 導入素材
   ↓
2. 剪掉NG及多餘片段
   ↓
3. 調整片段順序
   ↓
4. 加入自動字幕（好重要！）
   ↓
5. 加配樂
   ↓
6. 加疊圖（穴位位置圖、文字強調）
   ↓
7. 加片頭片尾
   ↓
8. 輸出（1080p，9:16）
```

### 字幕製作（重要！）

**點解要加字幕？**
- 好多人靜音睇短片
- 粵語有好多字發音相似，字幕幫理解
- 照顧聽障人士
- Hashtag可以由字幕提取

**CapCut自動字幕步驟**：
1. 點擊「字幕」→「自動字幕」
2. 選擇「粵語」
3. 自動識別後修正錯字
4. 調整字體、大小、顏色
5. 建議字體：思源黑體 Bold
6. 字幕位置：底部三分之一，避免遮住臉

### 配樂選擇

| 片種 | 建議音樂風格 |
|------|-------------|
| 穴位教學 | 輕鬆、禪意 |
| 痛症Q&A | 中等節奏 |
| 中醫冷知識 | 活潑、趣味 |
| 湯水教學 | 溫暖、家居感 |
| 診所日常 | 溫馨、輕快 |

⚠️ **版權注意**：
- 用CapCut內置音樂庫（免版權）
- 避免直接用流行歌曲
- IG Reels有自己嘅音樂庫

## 發佈策略

### 最佳發佈時間

| 平台 | 最佳時間 |
|------|----------|
| Instagram Reels | 中午12-1pm / 晚上8-10pm |
| Facebook Reels | 早上7-9am / 晚上7-10pm |
| 小紅書 | 晚上8-11pm |

### 標題公式

**公式**：[數字/問題] + [痛點] + [解決方案]

範例：
✅ 「3個穴位即刻紓緩腰痛！」（有數字）
✅ 「頭痛一直食止痛藥？試下呢個穴位」（問題開頭）
✅ 「為咩你嘅膝蓋痛越嚟越嚴重？」（引起好奇）

```

- 重點1

- 重點3

⚠️ [注意事項]

📱 WhatsApp預約：9XXX XXXX
📍 [診所名稱][屋邨名稱]
```

## 短片KPI追蹤

每條短片發佈後一週記錄：

| 指標 | 記錄位置 |
|------|----------|
| 觀看次數 | IG/FB原生數據 |
| 完播率 | Instagram Insights |
| 互動數（讚、留言、分享） | 各平台 |
| 帶來嘅follower | 觀察follower增長 |
| 帶來嘅查詢 | 記錄該週WhatsApp查詢 |

根據數據調整：
- 邊類內容最多觀看？ → 多拍類似
- 邊個片頭最抓眼球？ → 模仿風格
- 邊類片時最理想？ → 標準化時長
