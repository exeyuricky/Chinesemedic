# WhatsApp 病人通訊模板

呢個文件提供即用嘅WhatsApp訊息模板，可以直接設定為WhatsApp Business嘅「快速回覆」，提升溝通效率。

---

## 快速回覆設定

將以下模板設為WhatsApp Business嘅快速回覆：

| 快捷鍵 | 用途 |
|--------|------|
| /confirm | 預約確認 |
| /remind | 覆診提醒 |
| /thanks | 治療後感謝 |
| /address | 地址交通 |
| /hours | 營業時間 |
| /services | 服務項目 |
| /review | 評價邀請 |
| /holiday | 假期通知 |

## 使用指引

### 個人化調整

使用模板時記得：
1. 替換[方括號]內容（姓名、日期、時間等）
2. 根據情況調整語氣（長者用更正式啲，年輕人可以輕鬆啲）
3. 保持個人化感覺，唔好太機械

### 緊急情況處理

如病人訊息提到以下情況，**立即致電病人**：
- 嚴重疼痛加劇
- 出現新嘅嚴重症狀
- 中藥食後有不良反應
- 治療部位有異常反應

### 私隱保護原則

- 唔好喺訊息中討論其他病人情況
- 唔好透露診所內部資訊
- 敏感病情盡量線下討論
- 病人同意後先可以在社交媒體分享
